# MECH

Mechanical power mod for Minecraft Forge 1.20.1.

## Features

- Kinetic networks: water wheels, hand-crank generator, vulcanite gears and bearings
- Processing machines: press, oil press, quern, sawmill
- Fluid and energy distribution networks with per-block transfer limits and pipe losses
- Tiered steam machinery

## Building

    ./gradlew build

## Requirements

- Minecraft 1.20.1
- Minecraft Forge 47.x
- Java 17
